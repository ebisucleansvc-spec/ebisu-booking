# えびすクリーンサービス 予約フォーム

エアコンクリーニングの予約フォームです（GitHub Pages で公開し、送信内容は Google Apps Script 経由でスプレッドシートに保存、受付メールを自動送信）。

## ファイル
| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | フォーム本体 |
| `config.js` | **お店の情報・料金・GASのURL**（ここだけ書き換えればOK） |
| `gas/Code.gs` | GAS（予約の保存・受付メール・お店への通知） |

## 1. GAS（受付の仕組み）を設定する
1. Googleドライブで新しいスプレッドシートを作り、名前を「予約一覧」などにする
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消して、`gas/Code.gs` の中身を貼り付け、保存（Ctrl+S）
4. 上の関数選択で `setup` を選んで「実行」→ Googleの権限確認が出たら自分のアカウントで許可
   - 「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
7. `config.js` の `gasUrl: ""` の `""` の中にURLを貼り付けて保存

> Code.gs を修正したときは「デプロイ」→「デプロイを管理」→ 鉛筆マーク →バージョン「新バージョン」→「デプロイ」で反映します（URLは変わりません）。

## 2. 料金・お店情報を変える
- `config.js` の `price` / `phone` / `areas` などを変更
- 料金を変えたら `gas/Code.gs` の `PRICES` も同じ金額に変更（メールの金額はGAS側で計算します）

## 3. GitHub Pages で公開する
1. GitHub で新しいリポジトリ（例：`ebisu-booking`、Public）を作る
2. このフォルダの中身をアップロード（またはgit push）
3. リポジトリの「Settings」→「Pages」→ Branch を `main` / `(root)` にして「Save」
4. 数分後に `https://<ユーザー名>.github.io/ebisu-booking/` で公開されます

## 送信の流れ
フォーム送信 → GAS が受付番号を発行 → スプレッドシート「予約一覧」に1行追加（ステータス「未対応」）→ お客様に受付メール、お店に通知メール
